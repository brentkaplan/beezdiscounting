# beezdiscounting

Behavioral economic discounting analysis: score delay and probability
discounting tasks, fit hyperbolic and exponential discount functions,
score the 27-Item Monetary Choice Questionnaire (MCQ), compute
area-under-the-curve (AUC) and systematicity measures, and fit
scale-location-truncated beta (SLT-beta) mixed-effects models for
bounded indifference-point data.

## Install

From CRAN:

``` r

install.packages("beezdiscounting")
```

Development version:

``` r

# install.packages("pak")
pak::pak("brentkaplan/beezdiscounting")
```
