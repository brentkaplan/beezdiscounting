# Extract fixed effects from a structural choice model

Extract fixed effects from a structural choice model

## Usage

``` r
# S3 method for class 'beezdiscounting_choice'
fixef(object, ...)
```

## Arguments

- object:

  A `beezdiscounting_choice` object.

- ...:

  Unused.

## Value

Named numeric vector (identical to
[`coef()`](https://rdrr.io/r/stats/coef.html)).
