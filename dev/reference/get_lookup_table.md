# Get an internal instrument design table

Get an internal instrument design table

## Usage

``` r
get_lookup_table(items = NULL, instrument = NULL)
```

## Arguments

- items:

  **Deprecated.** Number of MCQ items (27 or 21), kept as a
  back-compatible alias for `instrument = "mcq27"` / `"mcq21"`
  (including positional calls like `get_lookup_table(21)`). Use
  `instrument` in new code; `items` cannot address the PDQ.

- instrument:

  Instrument key: `"mcq27"` (Kirby, Petry, & Bickel, 1999), `"mcq21"`
  (Kirby & Marakovic, 1996), or `"pdq"` (Madden, Petry, & Johnson,
  2009). Supply `items` or `instrument`, not both. The default (neither)
  returns the 27-item MCQ design.

## Value

Data frame with the complete item design. MCQ tables: questionid,
magnitude, kindiff, k_rank, ss_amount, ll_amount, delay (days). PDQ
table: questionid, block, h_rank, overall_rank (the item's position in
the pooled overall ladder used by the `overall_h` extension in
[`score_pdq()`](https://brentkaplan.github.io/beezdiscounting/reference/score_pdq.md)),
sc_amount, lu_amount, prob, theta (odds against), hindiff.
