# Get internal lookup table for the 27-item MCQ

Get internal lookup table for the 27-item MCQ

## Usage

``` r
get_lookup_table()
```

## Value

Data frame with the complete Kirby, Petry, & Bickel (1999) 27-item
design: questionid, magnitude, kindiff, k_rank, ss_amount, ll_amount,
and delay (days)
