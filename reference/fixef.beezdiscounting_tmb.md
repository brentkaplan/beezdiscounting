# Extract fixed effects from a TMB discounting model

Extract fixed effects from a TMB discounting model

## Usage

``` r
# S3 method for class 'beezdiscounting_tmb'
fixef(object, ...)
```

## Arguments

- object:

  A `beezdiscounting_tmb` object.

- ...:

  Unused.

## Value

Named numeric vector (identical to
[`coef()`](https://rdrr.io/r/stats/coef.html)).
